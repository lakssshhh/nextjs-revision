# Next.js Revision Quiz

Use these for quick self-testing.

1. What file creates a UI page?
   - A. `route.ts`
   - B. `page.tsx`
   - C. `proxy.ts`
   - **Answer: B**

2. What file creates an HTTP endpoint?
   - A. `layout.tsx`
   - B. `page.tsx`
   - C. `route.ts`
   - **Answer: C**

3. What does `[id]` represent?
   - A. Static folder
   - B. Dynamic route segment
   - C. Route group
   - **Answer: B**

4. Which route matches zero or more segments?
   - A. `[slug]`
   - B. `[...slug]`
   - C. `[[...slug]]`
   - **Answer: C**

5. Does `(auth)` appear in the URL?
   - A. Yes
   - B. No
   - **Answer: B**

6. Which hook is used for programmatic navigation?
   - A. `useRouter`
   - B. `usePathname`
   - C. `useSearchParams`
   - **Answer: A**

7. Which prefix exposes an environment variable to client code?
   - A. `SERVER_`
   - B. `NEXT_PUBLIC_`
   - C. `CLIENT_SECRET_`
   - **Answer: B**

8. Where should direct Prisma access happen?
   - A. Browser
   - B. Client Component
   - C. Server-side code
   - **Answer: C**

9. What does `notFound()` trigger?
   - A. `loading.tsx`
   - B. `not-found.tsx`
   - C. `error.tsx`
   - **Answer: B**

10. What are `@analytics` and `@team`?
    - A. Dynamic route parameters
    - B. URL segments
    - C. Parallel Route slots
    - **Answer: C**
